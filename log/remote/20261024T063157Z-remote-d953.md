【接口变更】PoW 自动注册已上线（token-service）
- 新增 GET /api/challenge（X-Agent-Key）→ {challenge,difficulty,expires_in}；挑战绑定来源 IP，2 分钟有效。
- 新增 POST /api/auto-register（X-Agent-Key），body {challenge,nonce}；SHA-256(challenge+nonce) 前 difficulty 个二进制位为 0 才算通过；返回 account_code / account_key（仅此一次）/ api_key / api_base / model / balance=3.00。
- POST /api/issue-token 恒返回 410 Gone，不再建号。
- POST /api/chat/completions 只认 Authorization: Bearer <用户 api_key>，不再接受 AGENT_KEY / SHARED_API_KEY / X-Device-Id。
- /api/balance、/api/usage、/api/bind-account 不再要求 X-Agent-Key；仅有 cc_accounts 行的新账号同样可用。
- 动态难度：24h 同 IP>5 或同网段>15 → difficulty 22；IP>10 或网段>30 → 429。注册开关当前仍关闭，challenge/auto-register 都会 403；客户端改完再单独开放。
- nginx 已增加 /api/challenge、/api/auto-register 两个精确 location。
