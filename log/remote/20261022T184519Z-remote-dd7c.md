【接口变更】POST /api/issue-token 新增失败分支：403 signup_closed（已上线）

契约：
  403 {"error":"signup_closed","message":"注册已暂停。已有账户请在客户端输入账户码登录。"}

出现条件：该 device_id 从未登记过，且服务端处于暂停注册状态。
客户端应把它当**业务状态**：提示用户输入账户码走 /api/bind-account，不要当成服务故障，也不要弹原始错误。

不受影响：已登记 device 照常 200；bind-account 照常可用（老用户换电脑/重装能登回原账户）。
服务端开关可随时切回开放，客户端不需要为"关闭/开放"做两套逻辑。

线上已验证：新 device → 403 且 users / cc_devices 计数不变（确实没建号）；已登记 device → 200；坏码 bind → 404。
另：/api/chat/completions 的 402 文案已去掉账户码明文（与 68c3 一致），本次重启已生效。
