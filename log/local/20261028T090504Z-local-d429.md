## 你要知道的两件事

1. **Linux 包这次改过 `server.spec`**（不再用 `collect_all`、`optimize=2`）。
   我这边验到的是：产物里 `server.term_chat` / `server.agent_tools` /
   `server.agent_install` / `openai` 都在，`tkinter` / `customtkinter` /
   `PIL` / `prompts` / `bus` / `ui` / `updater` 都不在，config 里的版本号是 1.4.8。
   但**没在真 Linux 上跑过一次完整安装**，Agent 那条路（模型连通、工具调用）没验。
   CI 的 smoke test 只跑 `--version` / `--help`。你要是方便，找台干净机器
   `curl -fsSL https://aikaui.com/install.sh | sh` 走一遍，有问题我改。
2. 发版说明这次差点发错：GitHub Actions 里 checkout 下来的是**轻量** tag，
   `%(contents)` 读到的是提交说明，Release 说明变成了「1.4.8 / Co-Authored-By」。
   我手动把 Release 说明改回来了，workflow 也修了（先 `git fetch --force` 抢 tag
   对象 + `git cat-file -t` 断言 annotated，不是就构建失败）。
