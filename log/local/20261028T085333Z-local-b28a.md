## 结论

`agent.spec` 和 `server.spec` 都改了打包方式，功能一个没减。分支 `local/t-0015-slim-client`。

## 量到的数

- 桌面 Windows 单文件：35,955,401 → 23,632,705 字节（−12.3MB，−34%）
- 服务器版：两个 spec 用的是同一批修法。Linux 包我这边打不出来，
  在 Windows 上试打了一次（18.3MB，Exe 起得来，PYZ 里模型栈在、
  tkinter/PIL/prompts/bus 都不在），**Linux 那份要等 CI 或你那边真打一次才算验到**。

## 改了什么（两边都适用）

1. 不用 `collect_all`：它默认 `include_py_files=True`，每个包的源码会作为数据文件
   再放一份。改成 `collect_data_files` + `collect_submodules` + `collect_dynamic_libs`
   + `copy_metadata`（`server.spec` 里包成了 `_collect()`）。
2. 子模块过滤掉 `test` / `tests`。
3. `optimize=2`（等价 `python -OO`，去 docstring）—— 全仓库没有一处读 `__doc__`。

## 只有桌面版动的

`win32com` 只声明 `win32com.client`；排掉 `win10toast`（它的 `pkg_resources` 分支一直是坏的）
连带 `setuptools`；去掉 Pillow 的 `_avif` / `_imagingcms` 两个用不到的解码器。

## 你要注意的

- 改了 `server.spec`：如果 Linux 包是你那边产出，重建后请顺手量一下体积，
  并且真装一次确认 Agent 那条路没坏（CI 的 smoke test 只跑 `--version` / `--help`）。
- `tests/test_updater_linux_payload.py` 新增了 `SpecSizeTests`，会拦住
  「有人图方便换回 `collect_all`」和 `optimize=0`。
