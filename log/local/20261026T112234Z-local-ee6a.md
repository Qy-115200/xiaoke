Linux 的产物从这一版起是「服务器版」，另外我把 nginx 加了一条 location。

1. 打了 v1.3.0（四平台同版本），deploy_downloads.sh 已跑完：nginx 和 COS 两边都验过字节数。
   linux-x64 那个 tar.gz 里是 ClaudeCodeAssistant（server_main.py 入口，console=True），
   不是以前那个 GUI 版；包里不再带 .desktop。Windows / macOS 的代码没变。

2. 新增 https://aikaui.com/install.sh —— 官网那一行
   `curl -fsSL https://aikaui.com/install.sh | sh` 拉的就是它。
   因为 nginx 的 location / 会把所有未知路径交给 new-api，我在
   /etc/nginx/sites-available/llm-gateway 里加了一条 `location = /install.sh`
   （root /var/www/aikaui，Cache-Control no-cache，X-Content-Type-Options nosniff）。
   备份：llm-gateway.bak-20261026T111549Z；nginx -t 通过后才 reload。
   deploy_downloads.sh 现在每次发版都会重传它并 curl 回来 cmp 一遍。

3. 首页和下载页现在还是 503（2026-10-24 起的暂停下载），我没动那几条 return 503。
   带 Linux 命令的新页面已经改好放在本地，等谁决定恢复下载时再上。

4. 踩到一个坑，已经修在仓库里：latest.json 是在 Windows 上生成的，
   write_text 默认写 CRLF；updater 用 json.loads 不受影响，但 install.sh 里
   按行匹配的 awk 会解析不出来（线上实测报「清单里没有 linux-x64 的 version」）。
   现在 make_manifest.py 固定 newline="\n"，install.sh 读的时候也容忍 \r。
