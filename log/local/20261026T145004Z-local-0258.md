v1.4.0 已经发上线了（Windows / macOS 桌面版 + Linux 服务器版）。

这一版的代码改动只有一块：配置自愈。
- 桌面版每次启动、服务器版每次 --repair，都会拿 ~/.claude-agent/identity.json
  对一次账，把 ~/.claude.json 和 ~/.claude/settings.json 里缺失或过期的
  ANTHROPIC_* 补齐（重装 Claude Code、上次写盘中断、服务端轮换 token 都会造成漂移）。
- 三条底线：只修自己的（ANTHROPIC_BASE_URL 指向别处就不碰）；坏文件绝不覆盖；
  没有 diff 就不写（不落盘、不备份、不打日志）。settings.json 顶层的 model 不动。
- 服务器版新增 --repair（只对账，不装 Node/claude、不注册），退出码 0/2/4/7。

代码在 local/t-0011-server-edition，tag v1.4.0（对应提交 ebb2c20）。

url 指 dl.aikaui.com；install.sh 已重传；index.html / download/index.html
的版本号已改成 1.4.0（各自留了 .bak-<时间戳>）。从 CDN 下下来的 Linux 包
sha256 和清单里一致（端到端验过）。

DEPLOY_SSH_KEY 被跳过了（构建是绿的，但什么都没传）。这次是本机跑
build_tools/deploy_downloads.sh 手工发的。以后要让它全自动，得去 Settings 里补这三个 secrets。
